- 版本：v0.6（2026-10-11）
- 状态：核心决策已确认；gen1–gen5 均已实施（含规模敏感性对照）；记录与结果见 §9

## 1. 总体框架

```
[1 崩盘定义: 双标准 A/B] → [2 输入信息集: 21 维技术面(Phase 1)]
→ [3 输出: 双标签二分类概率] → [4 数据结构: 周采样 + 因果滑窗]
→ [5 训练: 加权/Focal + Purged & Embargoed] → [6 评估: PR-AUC 为主 + 分年拆解]
```

每一环的选择必须与上下游自洽；本底稿即"为什么这么选"的唯一事实来源。

## 2. 崩盘定义：双标准并行

### 2.1 标准 A：日频收益率极值（保留自前期研究基线）

- 标签 `labelA_5d(t)`：未来 5 个交易日内，任一单日后复权收益 < -8% 记为 1
- 定位：直觉可解释的对照标签；已知缺陷是与股性耦合（低波动股几乎无正样本），仅作基线参照
- 可选变体（后续消融）：`labelA_20d`（未来 20 日窗口，与标准 B 同 horizon 对照）

### 2.2 标准 B：市场模型残差"崩盘周"（学界标准 + 预测化改造）

**第一步：剥离市场（Dimson 扩展市场模型，滚动估计）**

对每周 τ，用截至 τ+2 的过去 104 周数据回归：

```
R_i,τ = α_i + β₁·R_m,τ-2 + β₂·R_m,τ-1 + β₃·R_m,τ + β₄·R_m,τ+1 + β₅·R_m,τ+2 + ε_i,τ
```

- `R_i,τ`：个股周简单收益（周五收盘对齐，后复权价）
- `R_m,τ`：沪深300 指数周简单收益（BaoStock `sh.000300`）
- 前置/滞后市场项用于修正非同步交易偏差（前期研究共识做法）

**第二步：个股特异性周收益**

```
W_τ = ln(1 + ε_τ)
```

**第三步：崩盘周判定（滚动统计，防未来函数）**

```
flag(τ) = 1  当且仅当  W_τ ≤ mean_52(W_{τ-53 … τ-2}) - 3.2 × sd_52(W_{τ-53 … τ-2})
```

- 统计窗口 52 周，且**截止到 τ-2**：因 W 的残差含 ±2 周市场信息，τ-1 与 τ-2 尚未"干净"
- 停牌周不产生 W，直接跳过
- 与文献对照：Hutton et al. / Kim et al. 用完整财年均值/σ（ex-post 解释型研究）；本课题是预测任务，改用滚动统计（改造点，见 §7）

### 2.3 预测设定（已拍板）

- **采样**：每周五收盘后一个样本
- **标签**：
  - `labelB_4w(t) = OR(flag(t+1) … flag(t+4))`，即未来 4 周内出现至少一个崩盘周（贴近文献月度 CRASH dummy）
  - `labelA_5d(t)` 在相同的采样点上计算（保留其原 5 日事件口径；与 B 的 horizon 不同属设计选择，评估时只比"可学习性"，不直接比数值）
- **样本起点（burn-in）**：约上市后 3 年（β 窗口 104 周 + 统计窗口 52 周 + 2 周干净期）；样本不足时允许 β 窗口降为 52 周（参数可配置，需在实验记录中标注）
- **新股票处理**：剔除上市前 60 个交易日的样本（次新异质）

### 2.4 二期连续目标（暂不实现）

- NCSKEW（负收益偏度）、DUVOL（上下波动率比），公式以前期研究为准
- 计划作为并行预测头或回归任务，与二分类标签形成多任务

## 3. 输入特征（Phase 1：21 维技术面）

全部因果（仅用 t 及以前信息），日频计算，周五采样时取过去 60 个有效交易日的序列：

| # | 特征 | 定义 |
|---|------|------|
| 1 | log_r1 | ln(C_t / C_{t-1}) |
| 2 | log_r5 | ln(C_t / C_{t-5}) |
| 3 | log_r20 | ln(C_t / C_{t-20}) |
| 4 | vol5 | std(log_r1, 5) |
| 5 | vol20 | std(log_r1, 20) |
| 6 | atr14n | ATR(14) / C_t |
| 7 | park10 | Parkinson 波动率（10 日，基于 High/Low） |
| 8 | c_ma5 | C_t / MA5 |
| 9 | c_ma20 | C_t / MA20 |
| 10 | c_ma60 | C_t / MA60 |
| 11 | pctb20 | 布林 %b（20, 2σ） |
| 12 | hi252 | C_t / max(C, 252日) - 1 |
| 13 | rsi14 | RSI(14) / 100 |
| 14 | macdh | MACD 柱（12,26,9）/ C_t |
| 15 | vr5_20 | volMA5 / volMA20 |
| 16 | turn | 换手率（BaoStock 原生字段） |
| 17 | turn_ratio | 换手率 MA5 / MA20 |
| 18 | amtz20 | ln(成交额) 的 20 日滚动 z 分数 |
| 19 | c_rv20 | roll corr(log_r1, Δln(成交量), 20) |
| 20 | beta60 | 对沪深300 的 60 日滚动 beta |
| 21 | rs20 | 相对强度：log_r20 - 同期沪深300 收益 |

预处理规则：

- 停牌日（tradestatus=0）剔除，序列取最近 60 个有效交易日
- 1% / 99% winsorize，随后输入前用**训练段拟合**的 StandardScaler（防泄漏）
- 特征均为比值/有界量为主，天然跨股票可比（面板扩展前提）

### 数据结构

- 每个样本：`(60, 21)` 张量 + 两个标签 `(labelA_5d, labelB_4w)`
- 周采样导致样本窗高度重叠（相邻样本共享约 55 天）——正常且可控；换采样间隔为消融项

## 4. 输出

- Phase 1：二分类概率 P(crash)，标准 A / 标准 B 分别训练、同协议对照
- 模型保持小容量（LSTM 基线起步），后续 TCN / PatchTST 对比
- 二期：多任务（二分类头 + NCSKEW/DUVOL 回归头）

## 5. 训练与验证协议

- **损失**：加权 BCE（`--pos-weight`）起步 → Focal Loss 消融
- **切分**：禁止随机切分。单股票阶段用时间切分 + 边界清理；升级为 **Purged & Embargoed walk-forward**
  - 禁运期：标签窗口跨界（4 周）+ Dimson 尾部（2 周）→ **边界清理 ≥ 6 周**
- **模型选择**：按验证段 PR-AUC（或 Recall@top-k）早停，禁止按 loss 早停
- **评估**：PR-AUC 为主 + ROC-AUC + Recall@K%；**分年度/分 regime 拆解**（危机年 vs 平静年）；必须有全 0 基线对照
- **推进顺序**：宁德时代（波动大）/ 平安银行（对照）单股验证 → 30-50 只小池 → 面板 + walk-forward

## 6. Phase 2：文本与金融大模型接入（预留设计）

- **特征分块接口**：`price block（21 维/日）` + `text block（k 维/日）` + `fundamental block`，按日期对齐后拼接/注意力融合
- **对齐铁律**：一切文本/基本面按其"决策可用时点"打标——新闻按发布时间（盘后发布顺延 T+1）、财报按**实际披露日**（禁用报告期末日）
- **Jev（System One Model，TypeSafe AI）定位与用法**：
  - 形态：不生成文本，输入状态 + 预设问题，输出 Choice / Score / Noul（是非 + 校准概率）
  - 适用：全池高频低成本打分——每日新闻"是否含重大负面" Noul、财报公告情绪 Choice、风险 Score；70-500ms、$0.042/M 输入 token，适合批量
  - 局限（写论文须注明）：2026-09 发布、闭源商业 API、准确度不及顶尖 LLM、"零幻觉"仅指不跳出选项；版本漂移影响可复现性
  - 研究策略：与开源基线（FinBERT 情绪、规则关键词）做对照；API 输出按日留档快照；仅在 Phase 2 引入
- **开放项**：Jev API 可用性与输出稳定性的小样本试验（待负责人提供访问方式后执行）

## 9. 实施同步

### 9.1 单股（v0.2，gen1）

已实现（`scripts/run_weekly_baseline.py`，产物 `outputs/models/lstm/gen1/`）：

- 默认参数：beta_window=104、stat_window=52、sigma=3.2、clean_gap=2、horizon_weeks=4、seq_len=60、embargo_weeks=6、train_ratio=0.8、epochs=10
- 停牌周不产生 W 直接跳过；新股由特征/统计窗口自然 burn-in（约上市后 3 年）后进入样本
- 数据列：BaoStock 全字段含 amount/turn；指数自动回退基础字段；yfinance 源用 Amount≈Close×Volume、Turn 用量能代理

单股实证（sz.000001 与 sz.300750，2015–2026）：

- 崩盘周事件 ≈ 1 次/只/5–8 年（与文献 CRASH dummy 稀疏性一致）；trailing 与年度 ex-post 口径事件数同量级（均为 0–1）
- 测试段无 B 标签正样本，B 指标不可计算；A 标签测试段仅 1–2 个正样本，指标近随机
- 结论：单股仅作管线冒烟验证；**标准 B 的正式训练必须使用多股票面板**（下一步，见 PROGRESS.md）

### 9.2 面板（v0.3，gen2）

- 入口：`scripts/run_panel_baseline.py`，产物 `outputs/models/lstm/gen2/`
- 股票池：当期沪深300成分均匀抽样 40 只（1 只历史过短跳过，成功 39 只；**存在幸存者偏差**，全市场阶段修正）
- 面板规模：13,637 周样本（2017-11 ~ 2025-11），崩盘周合计 50 个；labelA 正率 3.09%、labelB 正率 1.43%
- 训练协议：池化 winsorize/标准化仅训练段拟合；按日期切分（split 2024-07-19）+ 6 周 purge；train 10,660 / test 2,749
- 首轮结果（测试段 2024-07 ~ 2025-11）：
  - A5d：普通 ROC-AUC 0.590；加权 ROC-AUC 0.715 / Recall 0.42 / F1 0.17
  - B4w：普通 ROC-AUC 0.649；加权 ROC-AUC 0.673 / Recall 0.27 / F1 0.06
  - 分年拆解提示时变有效性（2024 强于 2025）
- 结论：面板使双标签可训练并达到可讨论的基线下限；下一阶段按 PROGRESS.md 推进

### 9.3 扩展面板（v0.4，gen3）

- 股票池：2015–2026 沪深300 历史成分快照并集 662 只（消除成分前后视偏差；退市/吸收合并股保留，18 只因历史不足自动跳过）
- 面板规模：235,482 周样本（644 只有效）、崩盘周合计 1,036 个；labelA 正率 3.27%、labelB 正率 1.63%
- 协议：train 184,403 / test 47,364（split 2024-06-14，purge 6 周）；epochs 10、batch 128；池化标准化仅训练段
- 结果（测试段 2024-06 ~ 2025-11）：
  - A5d：普通 ROC 0.698（2024 分年 0.814）；加权 ROC 0.711 / Recall 0.46 / F1 0.17
  - B4w：普通 ROC 0.671（2025 分年 0.718）；加权 ROC 0.632 / Recall 0.50
- 与 gen2（40 只）对比：普通配置随规模显著改善（A5d 0.590→0.698、B4w 0.649→0.671）
- 工程：面板构建中间缓存 `panel_cache/`（特征 + 元数据校验，参数或股票池变化自动失效）

### 9.4 数据扩展与新协议（v0.5，gen4）

- 数据：历史补至 2013-01（burn-in 前移），最新补至 2026-10-09；指数同步扩展；662 只池
- 协议：`--train-start 2017-01-01`、`--split-date 2025-01-01`、embargo 6 周；新增 `--data-dir` 指定数据快照目录（`data/dataset2/`）
- 面板：653 只有效 / 309,677 样本 / 崩盘周 1,397（labelA 正率 3.53%、labelB 1.71%）；train 222,549（2017-01-06 ~ 2024-11-15）/ test 54,167（2025-01-03 ~ 2026-08-28）
- 结果（测试段 2025-01 ~ 2026-08）：
  - A5d：普通 ROC 0.709 / PR 0.120（2026 分年 ROC 0.869）；加权 ROC 0.674 / Recall 0.50（2026 分年 Recall 0.80）
  - B4w：普通 ROC 0.650 / PR 0.047；加权 ROC 0.647 / PR 0.054 / Recall 0.47
- 样本末端约 6 周「前瞻损失」：B 标签 4 周 horizon + Dimson 2 周干净期；属设计内行为，延长测试段需等新数据后重建标签
- 数据快照体系：`data/dataset1（40）/ dataset2（662）/ dataset3（1577）`，每份含指数；数据根目录已清理为快照结构

### 9.5 中证800 并集（v0.6，gen5）

- 股票池：中证800（HS300∪中证500）历史成分快照并集 1577 只（`--data-dir data/dataset3`）
- 面板：1541 只有效 / 711,848 样本 / 崩盘周 3,672（labelA 正率 4.23%、labelB 1.93%）；train 510,467 / test 124,590

- 结果：
  - A5d：普通 ROC 0.729 / PR 0.144（2026 分年 ROC 0.847）；加权 ROC 0.705 / Recall 0.51（2026 分年 Recall 0.75）
  - B4w：普通 ROC 0.676 / PR 0.052；加权 ROC 0.657 / Recall 0.46
- 规模敏感性（普通配置）：A5d ROC 0.709→0.729、PR 0.120→0.144；B4w ROC 0.650→0.676、PR 0.047→0.052 —— 规模到千级仍有小幅但一致的提升
